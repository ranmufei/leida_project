## 系统概述

### 什么是气象雷达数据管理与预测平台？

本平台是一个完整的气象雷达数据自动化采集、处理、管理和预测系统，能够：

- **自动下载**：每6分钟自动从中国气象局下载最新雷达图片
- **智能处理**：将雷达图片转换为站点时间序列数据
- **数据分析**：提供多维度数据查询和可视化分析
- **智能预测**：基于光流法和Prophet模型预测未来4-6小时趋势
- **Web管理**：友好的Web界面进行站点管理和数据查询

### 主要特点

- ✅ **全自动化**：数据下载、处理、预测全流程自动化
- ✅ **高精度**：基于0.01°网格精度的坐标映射
- ✅ **多模型**：光流法 + Prophet时序预测 + 集成预测
- ✅ **可视化**：ECharts图表展示数据趋势
- ✅ **易部署**：本地化部署，无需Docker

## 功能说明

### 一、站点管理

#### 1.1 添加新站点

**路径**：站点管理 → 添加站点

**必填字段**：
- **站点名称**：站点的中文描述名称（如"北京观测站"）
- **站点代码**：唯一标识码（如"BJ001"）
- **经度**：精确到小数点后4位（如116.4074）
- **纬度**：精确到小数点后4位（如39.9042）
- **海拔高度**：单位：米

**可选字段**：
- **所属区域**：用于分组管理
- **描述信息**：备注说明

#### 1.2 编辑站点

点击站点列表中的"编辑"按钮，修改站点信息。

> **注意**：经纬度是核心数据，修改后历史数据不会重新计算。

#### 1.3 删除站点

点击"删除"按钮删除站点。

> **警告**：删除站点会级联删除所有相关数据（雷达数据、预测记录），操作不可恢复！

---

### 二、数据查询

#### 2.1 查询站点数据

**路径**：数据查询

**查询条件**：
1. **选择站点**：支持多选，查询多个站点的数据
2. **时间范围**：选择开始时间和结束时间
3. **数据源**：
   - 实际数据：从雷达图片提取的真实数据
   - 预测数据：模型生成的预测数据
4. **dBZ范围**：过滤特定强度的回波数据

#### 2.2 查看结果

**统计卡片**：
- 查询结果总数
- 平均dBZ值
- 最大/最小dBZ值

**数据图表**：
- 蓝色实线：实际观测数据
- 绿色虚线：预测数据
- 阴影区域：置信区间（80%概率）

**数据表格**：
- 时间、dBZ值、等级
- 云影响因子（光伏预测用）
- RGB颜色值
- 数据质量评级

#### 2.3 导出数据

点击"导出CSV"按钮，将查询结果导出为Excel可打开的CSV文件。

---

### 三、预测分析

#### 3.1 选择预测方法

系统提供三种预测方法：

| 方法 | 适用场景 | 数据要求 | 预测时长 | 准确度 |
|------|----------|----------|----------|--------|
| **光流法** | 短期、快速变化 | 2张连续图片 | 0-2小时 | ⭐⭐⭐⭐ |
| **Prophet** | 中长期、季节性 | 7天历史数据 | 2-6小时 | ⭐⭐⭐ |
| **集成预测** | 综合考虑 | 满足两者 | 0-6小时 | ⭐⭐⭐⭐⭐ |

#### 3.2 创建预测

1. 选择站点
2. 选择预测方法
3. 选择预测时长（1/2/4/6小时）
4. 点击"开始预测"

系统会创建异步任务，后台处理。

#### 3.3 查看预测结果

**预测统计**：
- 预测时间点数量
- 预测时长
- 平均/最大dBZ值

**预测图表**：
- 预测曲线
- 置信区间开关（可显示/隐藏）

**详细数据**：
- 时间步
- 预测dBZ值
- 置信上限/下限
- 置信区间宽度
- 置信度（进度条）

**历史记录**：
- 查看所有历史预测
- 预测准确率
- 模型类型

### 四、下载管理

#### 4.1 手动触发下载

**路径**：下载管理

**操作步骤**：
1. 设置下载数量（1-10张最近图片）
2. 点击"立即下载"

#### 4.3 查看下载历史

- 观测时间
- 文件路径
- 文件大小
- 状态（成功/失败/重试中）
- 重试次数
- 错误信息（如果失败）

#### 4.4 下载统计

24小时下载统计柱状图：
- 绿色：成功下载数
- 红色：失败下载数

## 常见问题

### Q1: 登录后看不到数据？

**A**: 可能的原因：
1. 未添加站点：先在"站点管理"中添加站点
2. 数据未下载：在"下载管理"中手动触发下载
3. 时间范围不对：调整"数据查询"中的时间范围

### Q2: 预测失败怎么办？

**A**: 检查以下几点：
1. **数据不足**：
   - 光流法：需要至少2张连续雷达图片
   - Prophet：需要至少7天历史数据
2. **站点位置**：检查经纬度是否正确
3. **系统资源**：在"系统监控"中查看CPU/内存使用率

### Q3: 下载一直失败？

**A**: 可能的原因：
1. **网络问题**：检查能否访问中国气象局服务器
2. **URL错误**：查看下载日志中的错误信息
3. **存储空间**：检查磁盘空间是否充足

### Q4: 图表显示异常？

**A**: 尝试以下方法：
1. 刷新页面（Ctrl+F5 强制刷新）
2. 清除浏览器缓存
3. 检查浏览器控制台是否有错误

### Q5: 如何备份系统数据？

**A**:
1. **数据库备份**：
   ```bash
   mysqldump -u root -p gfs_weather > backup.sql
   ```
2. **雷达图片备份**：
   ```bash
   tar -czf radar_images.tar.gz backend/data/radar_images/
   ```

## 最佳实践

### 1. 站点管理

- **规范命名**：使用"地区+类型+编号"的命名方式（如"北京_观测_001"）
- **精确定位**：使用GPS设备获取精确经纬度
- **合理分组**：按区域或业务类型分组管理

### 2. 数据查询

- **分时段查询**：大量数据查询建议分时段进行（如每天或每周）
- **使用筛选**：充分利用dBZ范围和数据源筛选减少数据量
- **定期导出**：重要数据定期导出备份

### 3. 预测使用

- **短期用光流**：0-2小时预测优先使用光流法
- **长期用Prophet**：2-6小时预测使用Prophet
- **综合用集成**：重要决策参考集成预测结果
- **关注置信区间**：预测不确定时关注置信区间宽度

### 4. 系统维护

- **定期重启**：建议每周重启一次系统释放资源
- **监控资源**：关注磁盘空间使用率，及时清理
- **查看日志**：定期查看系统日志发现问题
- **数据备份**：每日备份数据库和重要文件

### 5. 性能优化

- **控制站点数**：单个系统建议管理不超过100个站点
- **定期清理**：定期清理过期的下载日志和临时文件
- **分时处理**：大量数据处理安排在系统空闲时段
