## 🎯 功能指南

### 1. Dashboard 主页

登录后您将看到Dashboard主页，包含：

#### 📊 统计卡片
- **总站点数**: 显示系统中的站点总数（默认5个）
- **雷达数据**: 显示雷达数据记录总数
- **预测任务**: 显示预测任务数量
- **下载任务**: 显示下载任务统计

#### ⚡ 快捷操作
- **新建站点**: 快速创建新的气象观测站点
- **创建预测**: 为站点创建预测任务
- **触发下载**: 手动触发雷达图下载
- **查询数据**: 查询雷达数据

#### 💻 系统监控
- **系统状态**: 显示后端服务运行状态
- **CPU使用率**: 实时CPU使用百分比
- **内存使用率**: 实时内存使用百分比
- **磁盘使用率**: 磁盘空间使用情况

#### 📥 下载状态
- **总任务数**: 下载任务总数
- **成功数**: 成功完成的任务数
- **失败数**: 失败的任务数
- **成功率**: 下载成功率百分比

### 2. 站点管理

点击顶部导航栏的"站点管理"进入。

#### 📋 站点列表
系统预置了5个示例站点：
1. **北京站** (BJ001) - 华北地区
2. **上海站** (SH001) - 华东地区
3. **广州站** (GZ001) - 华南地区
4. **深圳站** (SZ001) - 华南地区
5. **成都站** (CD001) - 西南地区

#### 🔧 站点操作
- **查看**: 点击"查看"按钮查看站点详细信息
- **编辑**: 点击"编辑"按钮修改站点信息
- **删除**: 点击"删除"按钮删除站点（有确认提示）
- **新建**: 点击"新建站点"按钮创建新站点

#### 📝 新建站点字段
- 站点名称（必填）
- 站点代码（必填，唯一）
- 经度（-180 到 180）
- 纬度（-90 到 90）
- 海拔（米）
- 区域（华北/华东/华南/华中/西南/西北/东北）
- 描述
- 状态（启用/禁用）

## 🔧 API测试

### 使用Swagger UI测试

1. 访问: http://localhost:8000/docs
2. 可以看到所有20个API端点
3. 点击任意端点可以测试
4. 需要先登录获取Token

### 使用curl测试

#### 健康检查
```bash
curl http://localhost:8000/api/v1/system/health
```

#### 登录获取Token
```bash
curl -X POST "http://localhost:8000/api/v1/auth/login?username=admin&password=admin123"
```

#### 获取站点列表（需要Token）
```bash
TOKEN="your_token_here"
curl http://localhost:8000/api/v1/sites/ \
  -H "Authorization: Bearer $TOKEN"
```

## 🆘 常见问题

### Q: 忘记密码怎么办？
A: 目前只有默认管理员账号。如需重置，请使用数据库直接修改或重新运行初始化脚本。

### Q: 如何添加更多测试数据？
A: 可以使用Swagger UI或前端界面手动添加，也可以使用API批量导入。

### Q: 前端无法连接后端？
A: 检查：
1. 后端服务是否正常运行 (http://localhost:8000)
2. 浏览器控制台是否有CORS错误
3. 网络连接是否正常

### Q: Token过期怎么办？
A: Token有效期为60分钟，过期后会自动跳转到登录页，重新登录即可。
