#### API接口清单

**认证API (2个)**
- POST /api/v1/auth/login - 用户登录
- POST /api/v1/auth/logout - 用户登出

**站点管理API (5个)**
- GET /api/v1/sites/ - 获取站点列表
- POST /api/v1/sites/ - 创建站点
- GET /api/v1/sites/{id} - 获取站点详情
- PUT /api/v1/sites/{id} - 更新站点
- DELETE /api/v1/sites/{id} - 删除站点

**数据查询API (3个)**
- GET /api/v1/data/query - 查询站点数据
- GET /api/v1/data/export - 导出CSV
- GET /api/v1/data/statistics - 获取统计

**预测管理API (4个)**
- GET /api/v1/predictions/methods - 获取预测方法
- GET /api/v1/predictions/site/{id}/latest - 获取最新预测
- POST /api/v1/predictions/site/{id}/predict - 创建预测
- GET /api/v1/predictions/site/{id}/history - 预测历史

**下载管理API (4个)**
- GET /api/v1/downloads/status - 获取下载状态
- GET /api/v1/downloads/history - 下载历史
- POST /api/v1/downloads/trigger - 手动触发下载
- POST /api/v1/downloads/retry - 重试失败任务

**系统监控API (2个)**
- GET /api/v1/system/status - 获取系统状态
- GET /api/v1/system/health - 健康检查
